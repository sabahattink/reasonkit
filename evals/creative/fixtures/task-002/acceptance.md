# TASK-002 starter acceptance

The fixture is intentionally plain and identical for every benchmark arm.

- Keep Next.js 14.2.15, React 18.3.1, and React DOM 18.3.1.
- Keep content.json values and public/mark.svg unchanged unless the evaluator
  supplies replacement facts.
- Use the local Arial, Helvetica, sans-serif stack; do not fetch fonts.
- Use the same browser, network restrictions, and target viewports for every
  arm.
- The participant may change the page and styles inside the starter to satisfy
  TASK-002.

The benchmark evaluates the resulting rendered experience, not the amount of
framework code.
