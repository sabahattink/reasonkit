# Creative Evaluations

Future cases should test point of view, hierarchy, systemic interaction,
anti-generic checks, target-size rendering, responsive behavior, and user
journey evidence.

Suggested cases:

- A visual brief with an intentionally generic first draft.
- A shared interactive canvas with meaningful state changes.
- A design that passes source checks but fails in the render.
- A reduced-motion or narrow-viewport acceptance check.

No visual case passes without a render and inspection record.
