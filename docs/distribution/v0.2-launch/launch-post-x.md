# X launch draft

## Post 1

ReasonKit v0.2.0 is released and frozen.

Adaptive reasoning + bounded agent orchestration for efficient AI work.

It loads the context a task appears to need, avoids unnecessary specialists, and makes verification/stop decisions explicit.

Release: https://github.com/sabahattink/reasonkit/releases/tag/v0.2.0

## Post 2

The honest boundary:

- prompt-pack, not a provider runtime
- no claim that one model becomes another
- no universal token-saving claim
- host still supplies models, tools, permissions, and execution

## Post 3

One frozen held-out debugging task:

- all four tested conditions: 4/4
- ReasonKit loaded only the debugging module
- 8.1% less provider input than Luna + Reliable Engineering in that run

Single task; not statistically significant. No quality-superiority claim.

## Post 4

The next 30 days are about adoption, not v0.3 architecture.

The test: can 20 real developers try it, and do 5 use it a second time?

Try one real task in one real repository. Tell us where it helped or got in the way. Do not share private code or credentials.

## Post 5

The useful signal is repeat use, not stars.

Feedback we need:

1. Was setup clear?
2. What task category did you try?
3. What route/context was selected, if visible?
4. Would you use it again?
