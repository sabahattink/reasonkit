# Manual outreach template

Use only for a small, manually selected list of people whose public work suggests they can test an agent workflow on a real repository. Personalize every message. Do not scrape private data, bulk-send, or imply endorsement.

## First message

Hi {name} — I saw your work on {specific public project or topic}. I’m testing ReasonKit v0.2, a small prompt-pack for adaptive reasoning and bounded agent orchestration.

It is not a runtime or a new agent framework. The practical test is simple: load the v0.2 kernel, generic adapter, and one matching protocol into your coding-agent workflow, use it on one real task, and tell me where it helped or got in the way.

Release: https://github.com/sabahattink/reasonkit/releases/tag/v0.2.0

No need to share private code or outputs. Would this be relevant to one task you already planned to do?

## Follow-up after a first try

Thanks for trying it. The most useful signal for this sprint is not a star: did you use it a second time, and did the second task feel easier, clearer, or more constrained? A one-line answer is enough.

## Selection checklist

- Publicly visible work in agent tooling, developer tools, open source, or context efficiency.
- Likely access to a real repository or reproducible task.
- No sensitive personal data needed.
- No assumption that the person wants a sales conversation.

## Record after contact

Record only: date, segment, whether contacted, whether they tried, first/repeat use, task category, friction, and feedback link or opaque note. Do not store private repository content.
